## PEARL Signature — project rules for agents

**What this is:** premium Canadian online Nigerian food store. Phase 1 (design
system + public storefront) is complete; later phases add MongoDB Atlas M0,
Cloudinary, Stripe, auth and the admin dashboard — see `docs/PHASE_PROGRESS.md`
and `docs/PROJECT_SPEC.md`. **Do not start a new phase without explicit approval.**

**Commands (run from repo root):**

```bash
npm run lint          # ESLint — must be zero errors/warnings
npx next typegen && npm run typecheck   # tsc --noEmit (typegen first when routes change)
npm run test          # Vitest (23 tests) — must stay green
npm run test:e2e      # Playwright smoke (needs `npx playwright install chromium` once)
npm run build         # production build
npm run screenshots   # 4 routes × 360/390/768/1024/1440 + horizontal-overflow check
```

**Hard rules:**
- Never invent prices, hours, contact details, delivery regions or reviews —
  unknowns stay "pending". No "bestseller" claims.
- No raw hex in components — use the tokens in `src/app/globals.css`.
- Gold is restrained: never small gold text on cream (use `gold-700`).
- Fonts: Fraunces (display) + Manrope (UI) via `next/font` only.
- Section padding belongs to the `Section` `padding` prop — never override
  vertical rhythm via className (responsive variants fight in the cascade).
- No hotlinked images; `FoodMedia` is the temporary placeholder and the
  Cloudinary/`next/image` migration point.
- No Supabase/Firebase/Postgres; no secrets in source.
- Every interactive element needs a visible `focus-gold` ring and must respect
  reduced motion (`MotionProvider` sets `reducedMotion="user"`).
- Commit this `AGENTS.md` as-is (the Next.js block above is regenerated by
  `next dev`).
